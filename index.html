About the Project

Messenger is a real time web based chat application for registered users who need a secure and organized way to communicate online. It allows users to send public, private, and group messages. This product is useful for teams, classmates, or communities that need fast collaboration. This application solves the problem of miscommunication by providing one secure platform for messaging, user authentication, group channels, and role based access.
